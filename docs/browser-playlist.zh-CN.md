# 浏览器试玩清单

检索：2026-11-08。已读取开发者或游戏平台的游戏页面与运行说明；未实际操作完成游戏，加载情况仍取决于浏览器与网络。下列链接均提供网页游戏入口，不要求下载客户端。合作与对战分开体验，不意味着本项目要同时做两种模式。

## 双人合作

### 1. Mask/Off：优先试玩

[开发者页面 / Run game](https://quantumcookie.itch.io/maskoff)

- 3D、俯视、同机本地双人合作解谜平台游戏，Unity 制作，GGJ 2026 作品。
- 网页提供 Run game，平台列有 HTML5；页面同时提供下载版，网页试玩请选择 Run game。
- 两名角色一起解谜寻找下一关的门。控制方式以游戏内说明为准。
- 参考重点：俯视镜头、双方站位、机关可读性，以及一个小体量作品如何建立合作目标。不是搬运游戏的完全对应案例。

### 2. Duo Vikings：合作机关补充

[Poki 在线玩](https://poki.com/en/g/duo-vikings)

- **2D**，仅借鉴合作规则；不是本次 3D 美术参考。
- 同一台电脑、同一键盘。玩家一 A/D 移动、W 跳跃、S 交互；玩家二方向键对应操作。
- 踩机关、开门、升降平台、破坏物体，共同到达出口。
- 参考重点：一人开路另一人通过、能力分工和逐关教学。

## 双人对战

### 3. Tank Duel 3D：优先试玩

[TwoPlayerGames 在线玩](https://www.twoplayergames.org/game/tank-duel-3d)

- 3D 场景中的双人坦克竞技；移动主要发生在地面，不是自由三轴战斗。
- 同一台电脑、同一键盘；可对朋友或电脑。
- 玩家一 WASD 移动、Q 攻击；玩家二方向键移动、空格攻击。
- 参考重点：少量操作、小地图、清晰弹道与回合制胜负。适合检验半天对战原型的目标规模。

### 4. TankHit：掩体与弹药补充

[TwoPlayerGames 在线玩](https://www.twoplayergames.org/game/tankhit)

- 3D 迷宫 / 竞技场、双人坦克对战；移动主要在地面。
- 同一台电脑、同一键盘，也可与 CPU 对战。
- 玩家一 WASD 移动、T 攻击；玩家二方向键移动、P 攻击。
- 弹药容量为 5，率先命中 5 次获胜，场内有强化道具。
- 参考重点：遮挡、绕侧、弹药与道具如何改变出手决策；首版无需照搬所有强化道具。

### 5. Two Ball 3D：极简竞赛补充

[TwoPlayerGames 在线玩](https://www.twoplayergames.org/game/two-ball-3d)

- 3D 跑道、双人比谁先掉落；属于竞赛，不是互相攻击或合作。
- 同机键盘，分别用 A/D 和左右方向键控制。
- 参考重点：极少输入如何形成立即理解、快速重开的完整循环。

## 建议顺序

先体验 Mask/Off 约 5 分钟，再体验 Tank Duel 3D 约 5 分钟；对合作或对战哪条路线更感兴趣，再深入其余案例。这只是建议体验时长，不代表通关时长。游戏平台可能有广告或加载等待。

试玩后各自记录：多久理解操作、何时需要与队友交流、输赢是否看得懂、是否想再玩一局。用这些反馈决定一条最终路线。

| [Bumper Cars Soccer](https://poki.com/zh/g/bumper-cars-soccer) | 3D 场地、双人碰碰车足球对抗；同机，玩家一 WASD、玩家二方向键 | 最优先试玩：驾驶、撞球、射门的目标直观；Hi3D 可生成车壳，底层运动和碰撞独立实现 |

| [Two Button Bounce](https://poki.com/zh/g/two-button-bounce) | 2D 合作平台解谜，同机；W 与上箭头分别跳跃，R 重开 | 每人只需一个动作，合作取钥匙，一人抵达出口即可通关；适合研究半天范围控制 |

**结合半天与 Hi3D 的新候选：只做 1v1 碰碰车足球。** 一个球场、两辆镜像规则的车、一颗球、两个球门、进球后复位，首版去掉跳跃、道具、车辆升级和复杂拟真驾驶。生成车壳只负责视觉，使用简单形状完成碰撞。此项是新增独立对战候选，尚未取代合作建议，也未决定开始实现。

如果只抽出十分钟：先玩 Bumper Cars Soccer，再玩 Max and Mink 或 Two Button Bounce，比较你们更愿意做空间对抗还是共同解谜。游戏运行入口可能有广告与加载等待，操作以实际游戏界面为准。
