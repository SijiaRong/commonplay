# 按现成 3D 资源选择游戏类型

更新：2026-11-08。新增约束：黑客松主题为 3D，希望采用现成 3D 资源较多的游戏类型。合作与对战仍是互斥候选，最终只选一条。

## 建议

**合作优先：低多边形遗迹 / 地牢双人闯关。对战优先：低多边形 1v1 小型射击竞技场。** 两类都可以用现成场景模块、角色与道具搭建，且能用空间遮挡、地形和高低差表现 3D 的玩法价值。

这里的排序是基于下列实际可查资源与集成成本的工程判断，不是对所有资源平台进行数量统计的结果。当前仅核验资源页面，尚未下载、导入或验证具体引擎中的表现。

| 独立候选类型 | 现成资源能提供什么 | 团队仍需完成什么 | 推荐度 |
| --- | --- | --- | --- |
| 双人合作遗迹解谜闯关 | 模块化墙地、柱子、门、箱桶、角色与基础动画 | 一组互补交互、三道机关、双人摄像机与共同通关 | 合作首选 |
| 1v1 小型射击竞技场 | 枪械、弹药、箱子、掩体、角色和场景模块 | 移动、瞄准、命中、得分与复位；联网另计 | 对战首选 |
| 双人合作 3D 平台闯关 | 平台、环境件、角色、可借鉴的控制器模板 | 跳跃手感、协作机关、坠落复位与镜头 | 合作备选 |
| 1v1 卡丁车竞速 | 车辆、卡丁车角色与道路组件 | 驾驶手感、碰撞、检查点和赛道；不是有车模就能完成 | 对战备选 |
| 1v1 近战格斗 | 人物、武器、部分基础动画 | 专用动作、受击、判定、连招和动画衔接 | 首版降低优先级 |
| 外勤 + 情报控制台合作 | 可用现成室内环境 | 需要另做大量控制台界面，且一侧可能主要是 2D 界面 | 保留机制参考，资源优先时靠后 |

## 两个可选的最小方案

### 方案 A：只做双人合作——遗迹机关闯关

两名探险者共同打开遗迹出口。一人可以放置或移动能量装置，另一人可以激活远处机关；双方轮流为对方创造通路。

- 内容：一个小遗迹、三道递进机关、一个共同出口，单局约 5 分钟。
- 3D 价值：绕柱观察、上下层通路、视线遮挡和物体朝向参与解谜。
- 资源组合：一个遗迹场景包 + 同风格角色 + 箱子、门、能量装置。
- 首版只做机关与合作通关；敌人 AI、战斗、背包和装备成长不纳入范围。
- 验证：双方都有事做，必须协作，失败能快速复位。

### 方案 B：只做双人对战——小型射击竞技场

两名玩家在有掩体和高低差的小场地中决斗，只有一种易读的能量武器；率先取得指定击倒数的一方获胜。

- 内容：一个对称场地、同一角色的两种颜色、一种武器、命中反馈、计分与复位。
- 3D 价值：掩体、绕侧、距离与高低差影响攻防。
- 资源组合：枪械道具包 + 一套场景模块；若使用第一人称视角，可减少第一人称全身动作制作，但对方角色仍需移动与受击表现。
- 优先本地分屏或现场局域网，具体方案待引擎选定；公网匹配、复杂技能和多武器不纳入首版。
- 验证：能迅速看懂命中与胜负，复位不产生明显不公平，输家愿意立刻再战。

## 选型前的快速资源验证

选定方向后，先导入一个角色、一段动画和一个场景模块，验证比例、材质、骨骼、碰撞与性能；确认后再批量导入。尽量使用同一作者或同系列风格，减少材质、比例与骨骼适配工作。最终仍需先完成可玩切片，再扩充资源数量。
