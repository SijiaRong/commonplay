# 小熊滑滑梯 · 局域网派对服务器

在一台电脑上开服，同一 Wi-Fi 下的手机和电脑用浏览器打开就能一起比赛。服务器同时提供游戏页面和联机房间。

## 在 MacBook 上开服

1. 安装 Node.js 20 或更新版本（[nodejs.org](https://nodejs.org) 下载 LTS 版，或 `brew install node`）。
2. 在仓库根目录运行：

   ```sh
   cd teddy-playground/server
   npm install
   npm start
   ```

3. 终端会打印地址，例如：

   ```
   小熊滑滑梯派对服务器已启动（每个房间最多 4 人，含机器人最多 16 名选手）
     本机打开:   http://localhost:4180
     同一 Wi-Fi: http://192.168.1.23:4180
   ```

   手机连同一个 Wi-Fi，打开「同一 Wi-Fi」那一行的地址。macOS 第一次运行时如果弹出“是否允许 node 接受传入网络连接”，请选择允许。

## 怎么玩

- **单人**：首页选「机器人陪跑」数量，点开始。不加机器人时可以慢慢跑、随时停下观察机关。
- **多人**：一人点「创建房间」，把 4 位房间码或「复制邀请链接」发给朋友；其他人在首页输入房间码，或直接打开链接。房主可加机器人补位，然后点「开始比赛」。
- **积分规则**：五关所有人都跑完，不淘汰。每关按到达顺序得分，N 人比赛时第 1 名得 N+2 分、第 2 名 N 分、第 3 名起依次减 1，最少 1 分；没到终点 0 分；第五关双倍。第一个真人到终点后，本关再给 30 秒；所有真人都到了，再等 4 秒就结算。机器人先到不会开始倒计时。
- **操作**：电脑 WASD 移动、空格跳、E 技能、R 复位。手机左半屏按住拖动移动，右下角「跳」、技能和复位按钮。
- **断线**：手机锁屏或切换网络后回到页面会自动重连，回到原来的位置；掉线期间由机器人代跑，90 秒内没回来就让出座位。比赛中途加入的人会先观战，下一局再上场。

## 设置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 4180 | 端口 |
| `MAX_PLAYERS` | 4 | 每个房间最多几位真人，最大 16。真人加机器人合计最多 16 名选手 |

例如：`MAX_PLAYERS=8 npm start`。

## 测手机性能

地址后加 `?fps=1`，页面顶部会显示帧率和画面中的选手数。单人选「15 个」机器人陪跑就是 16 人同屏的压力测试。记下不同手机在 4、8、16 人时的帧率，再决定房间上限。

## 技术说明

- 比赛逻辑在 [`../dist/solo/party.js`](../dist/solo/party.js)：在原有五关引擎上改为积分制，单人（浏览器 Web Worker）和多人（本服务器）共用同一份代码。
- 服务器每秒推进 60 次模拟，每秒给每位玩家发 30 次状态（约 0.5KB），每关开始时发一次赛道数据（约 135KB）。实测一核可同时跑约 300 个 16 人房间，瓶颈在手机渲染而不是服务器。
- 自己的角色目前也由服务器决定位置，局域网下操作延迟约 0.1 秒。以后部署到公网服务器时，需要加本地预测，让自己的角色先动、再由服务器校正。
- 自动检查：在仓库根目录运行 `node tools/check-teddy-party.mjs`、`node tools/check-teddy-finish.mjs`、`node tools/check-teddy-trap-respawn.mjs`。
