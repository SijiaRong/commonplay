# 泡泡星城

从当前工作区的 teddy-playground/dist 独立复制，包含单人闯关、经典滑梯和自由练习。在本目录运行 `python3 -m http.server 8771 --bind 127.0.0.1 --directory dist`，浏览器打开 http://127.0.0.1:8771/ 。

## 多人房间

在仓库根目录执行以下命令（Node.js 20 或更新版本）。服务器同时提供星城页面和 WebSocket 房间。

```sh
cd teddy-playground/server
npm ci
npm run bubblecity
```

电脑打开[多人房间](http://localhost:4181/?mode=party)，或从游戏首页点「多人房间」。输入昵称、选角色，点击「创建房间」。朋友连同一个 Wi-Fi，用终端打印的局域网地址打开游戏，输入四位房间码，也可以直接打开邀请链接。房主可添加机器人并开始比赛。默认每房可容纳 4 位真人，支持独自开局；通过 `MAX_PLAYERS` 可调到 16 位，机器人与真人合计最多 16 位。

比赛采用五关累计积分，最后一关双倍。中途加入可观战，比赛中掉线后 90 秒内可回到原座位。联机使用星城的关卡、角色、滑行物理和场景，房间码、积分、按钮输入与状态快照复用小熊派对服务。普通静态服务器可以继续运行单人模式。服务端和联机客户端共用仓库里的 `teddy-playground` 文件，开服时请保留目录结构。

三个模式共用 11 名直立人型角色。铆墩、切线、回声、挑杆、卷尺、续航和反弹使用完整桌面模型，每款约 37–67 MiB。选角面板先显示头像，选中角色时才加载对应模型；下次进入会加载上次选中的角色。

工作室六面图取自定稿的 bubbleport-demo/dist/room/workshop，同一套图用于背景与环境反射。赛道与经典滑梯的主体使用象牙涂层和薄荷树脂，配色取自泡泡星城概念图。每种表面使用可平铺的底色、切线空间法线和粗糙度贴图，桌面为 1024 像素，触屏设备为 512 像素。这两种涂层的贴图位于 dist/slide/surfaces，由 tools/make-surface-maps.py 生成。带颜色的树脂护栏共用树脂的法线和粗糙度，保留路段识别色。加速箭头、终点格纹和毛绒角色沿用原 demo。第三方资源沿用原 demo 的来源和许可范围。

单人赛道的门架饰条和经典滑梯的白蜡木支件使用 Jenelle van Heerden 的 [Ash Veneer](https://polyhaven.com/a/ash_veneer)，按 [Poly Haven 的 CC0 许可](https://polyhaven.com/license) 使用。基于原 demo 的同款贴图，将底色对比度降低 3%，再混入 2% 象牙色；法线和粗糙度保留原采样值。

单人关卡回转弯内的土星灯使用蜜桃色透明亚克力球与黄铜轨道环。球体按 Lost Marbles 的球面入射、出射与上一帧场景折射方法绘制，沿折射路径分六层采样流纹和微泡贴图。可在[材质标本室](https://commonplay-surface-atlas.rongsijia.chatgpt.site/#port)并排查看原彩漆灯球。

试玩右上角的「设置」可实时调整房间亮度、航标灯亮度和触控按钮大小，选择会保存在当前浏览器。单人闯关与经典滑梯均可在泡泡星城与 Lost Marbles 赛道材质间切换，影响路面、支架、饰条及涂色护栏。角色、工作室背景、软垫、灯具、标记和碰撞固定。Lost Marbles 选项使用原橡木和白蜡木的底色、法线、粗糙度及染色材质参数。自由练习仅提供适用于该场景的设置。

滑行以当前移动方向的下坡角度判定。运行 `node --test tests/direction.test.mjs` 可验证同一斜面上下坡、横切和静止的行为。

五关都使用圆角铺砖广场和分层台地承托赛道。[第一关](review/park-stage-1.jpg)沿街布置摩天轮、汽水咖啡馆与露天茶座，[第二关](review/park-stage-2.jpg)在回旋赛道外围布置土星地标、玻璃穹顶馆和火箭发射塔。[第三关](review/park-stage-3.jpg)围绕穹顶馆布置花池与长椅，[第四关](review/park-stage-4.jpg)用珊瑚色台地串起摩天轮、弧面商店与露天咖啡座，[第五关](review/park-stage-5.jpg)在火箭发射塔和星港总站对面设置土星广场，沿赛道外围靠近终点漏斗。设施取自环港线的轻量化景观模型，仅参与渲染。在材质编辑器选择「游乐场底座与景观」可单独查看。

第二关默认赛道以土星回旋滑梯接终点。最后一段直坡切向接入 17 单位宽的弯道，中心线半径 14.5，沿 180° 转角下降 12 单位，出弯再经过 14 单位直道进入检查线。随关卡布局向外侧镜像。弯道路面和内外护栏参与碰撞，灯标、包边、板缝和铆钉为视觉件。可查看[结构预览](review/stage-2-saturn-structure.jpg)和[材质预览](review/stage-2-saturn-finish.jpg)。珊瑚橙护板的底色、OpenGL 法线、粗糙度和土星发光图案由 `tools/make-surface-maps.py` 生成。运行 `node --test tests/*.mjs` 可检查左右折返布局下从入口前到终点的实际角色物理。

## 关卡材质编辑器

从单人闯关右上角进入「材质编辑」，可沿用当前种子和关卡。也可在上述服务中直接打开[编辑器](http://127.0.0.1:8771/editor/)。选择关卡、赛段，再点选组件或从列表定位。编辑器调用试玩的 buildShow、CourseView 和六面工作室天空盒加载器。材质覆盖按浏览器来源、种子、关卡与组件保存；从编辑器返回同一来源的试玩即可看到修改。可逐材质槽还原。

编辑器默认聚焦当前赛段；切换赛段会同时隐藏其他赛段，点击「关卡全景」可恢复整关。编辑器与试玩共用场景渲染、相机基础参数和环境设置。在「场景环境」中可切换工作室六面图与中性灰背景、旋转环境或调整房间亮度。「恢复试玩默认环境」将背景恢复为工作室，旋转归零，亮度恢复至 42%。

材质选择器提供 28 种固定预设，包括 17 种试玩材质、8 种实验台材质和 3 种 Lost Marbles 木纹。每关的横幅与路牌另列在「本关印刷图案」，文字和底色取自该种子下实际生成的赛段。薄荷亚克力来自实验台，使用清漆、带色透射和四次深度采样的浇铸流纹；试玩的蜜桃气泡亚克力沿用土星灯球的六次球内采样。独立发布目录中的 `dist/vendor/bubbleport-materials.mjs` 随包收录了[实验台的主源码](../material-atlas/dist/original/bubbleport/materials.mjs)。
