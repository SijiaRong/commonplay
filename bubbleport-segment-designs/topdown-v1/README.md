# 泡泡星港 · 六段赛道俯视设计 v1

本轮集中在路线、障碍布局与过关节奏。借用本项目小熊「玩具门廊」的平地闯关—直滑梯—摆锤—波浪地板—回旋滑梯结构，用内置 ImageGen 分别绘制六段泡泡星港风格的独立俯视概念。美术沿用原始泡泡星港的象牙树脂、薄荷护壁、蜜桃软包、黄铜连接件和暖色指示灯。已有组件在后续制作时优先复用，不在这轮扩展资产采购或建模计划。

## 共用设计基准

- 角色参考直径1.3，赛道净宽19.2设计单位；净宽是两侧边界间距，局部机关会占用路面。
- 五个直段的水平投影长度先按64设计；回旋段为中心半径24的180°弧，两端各16直线。不同图片保持同类宽槽、低护栏与材质，不把图像像素比例当成尺寸测量。
- 每段入口保留8–10单位观察/准备区，出口保留至少10单位恢复空间；关卡边界不使用大门遮住读图。
- 主体路面连续。装饰集中在护栏接头和灯罩，不在可行走区域堆景观。
- 关卡允许失败后恢复；本轮是图像与设计规格，没有新增玩法代码、碰撞或通关验证。

## 01 · 双摆锤廊

在Z=23与41设置两把大摆锤，锤头半径暂定1.8；横扫方向均为左右，两锤相位相反。入口Z=0–10和出口54–64无机关。锤间留完整等待区，玩家只需依次判断，不要求同时躲开两锤。横梁与支点在画图时用透视/半透明方式处理，以免俯视被横梁遮住；实际模型仍需正常悬挂支架。

建议周期先用4秒、第二锤错开2秒；命中拟造成减速/推移而非直接淘汰。图中虚线为运动范围，实线为某一时刻姿态。后续需验证低速玩家能在锤间停下，外侧不能靠墙永久避过全部挑战。头部外观优先评估现有土星锤头复用。

## 02 · 星港移门

在Z=18、33、48设置三排门，每排三个约4.8宽的有效门洞。门板水平缩入壳体，区别于前一轮的升降门。三排之间留15单位换线空间；初始展示开口依次在中、左、右。每排都必须至少保留一个可通行洞，不允许出现整排封死。

建议每排6秒周期、相邻排错相；在门洞切换期间维持至少一个旧洞或新洞足够宽，预警灯提前0.8秒。后续复用小熊移门的玩法逻辑，外观换为星港壳体。主设计不以强制跳门替代选洞。

## 03 · 气泡柱群

固定柱共9根，半径1.15。Z=18的X为−6、0、6；Z=31的X为−3.5、2.5、7；Z=44的X为−7、−1、5。柱间最窄设计净距2.2，角色直径1.3；护栏侧缝不作为强制通路。第一排让玩家理解绕行，第二排错位，第三排提供可选择的出口。

不加入移动机关或弹射力，优先验证连续跑动时的提前转向。三排之间可重新选线，不能为了画面热闹增加柱子封住路线。

## 04 · 苏打直滑梯

入口平台Z=0–10；Z=10–48连续下降8单位；Z=48–64水平承接。坡面两枚低软包分别位于Z=24和38，左右交错，各自不超过约半幅宽。换线幅度要轻，不做高速急S弯；末端两侧减速条、中央通道保持连续。

俯视无法可靠表达垂直高差，不能从亮暗反推坡度。后续纵断面建议沿余弦曲线平顺接坡，入口/出口斜率归零；先验证坐下、滑行、站起动画与接触稳定性。软包可评估复用现有胶囊外观。

## 05 · 土星回旋滑梯

两个直线接口均朝图下方：左下为入口，向上行进；沿上方半圆顺时针回转；右下为出口，向下离开。宽19.2，中心半径24，内半径14.4，外半径33.6，弧中下降8单位，尾段逐渐变平。弯中不放机关，专门教学滑行转向；出弯设置较长制动区。

内线短、外线容错大，但不设隔离墙强迫玩家锁线。内庭保留空白或平面土星图案，避免中间地标挡住对弯道的观察。不得生成绕一整圈的螺旋、闭合环或连接两尾的横桥。

## 06 · 星浪踏板

Z=16–48为四排三列共12块低位活动地板，排间保留固定窄等待踏带；两侧各2.6宽的固定绕行廊贯穿整个挑战区。地板只做小幅下沉，不默认生成深洞。展示状态依次为第一排中间高、第二排左侧高、第三排中/右高、第四排右侧高。最终图中薄荷色是当前可踏的高位面板，象牙色为其他相位；↑↓仅示意高度变化，不是平面前后滑动。

设计目标是让玩家以“中→左→中/右→右”阅读下一排。建议每块6秒循环，预警至少0.8秒、排间错相，保持可等候的固定落脚处；波形动画中始终维护可达路线。安全侧廊以距离换取低风险。低位地板的实际间隙、可跨越宽度和跳跃辅助需接入后标定。

## 连成一关时的建议顺序

移门 → 柱群 → 直滑梯 → 双摆锤 → 星浪踏板 → 回旋滑梯 → 简单终点。

先在平地练选线，再进入滑姿；落地留缓冲后引入择时；用回旋滑梯改变路线方向。六张图是独立模块方案，不表示已经拼成完整比赛。周期、速度与完成时间都尚未实测。
