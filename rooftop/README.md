# 风港快递 · 局域网原型

默认进入自由练习。WASD 或方向键移动，空格跳跃，R 复位。玩家进入空房间时生成一个随机种子，后加入的玩家沿用该房间的种子。当前练习使用第一关，完成后回到起点。复测指定布局可在空房间打开 [固定种子示例](http://localhost:4178/?seed=20261108)。

首次克隆请先在本目录运行 `python3 fetch-runtime.py`（需要 curl），再运行 `npm ci` 和 `npm start`，本机打开 http://localhost:4178，同伴用本机的局域网 IP 和端口 4178 加入。PORT 环境变量可更改端口。启动时设置 `GAME_MODE=race` 可运行五轮选卡与淘汰赛，机器人补位至 50 名选手。

## 实现与资源

- 房间模拟和浏览器从同一份 Lost Marbles 生成器运行 buildShow(seed)。服务端使用其路径、分岔、起跑位、动态碰撞体和终点，浏览器使用生成的几何描述与 CourseView 构建当前关卡。动态障碍按同一关卡时钟计算姿态。
- 当前局域网服务按明确路径提供生成器、几何、程序化标牌及其依赖。原站扫描纹理和摄影环境使用本项目的低模材质与背景替代。服务器以 60 Hz 推进模拟，以 20 Hz 发送快照。
- [人偶 GLB](../assets/windport/courier.glb) 是当前原创角色的分件模型。[屋顶赛道 GLB](../assets/windport/harbor.glb) 保留了早期原创路线的静态样件。
- 本机研究版依赖仓库忽略目录 ../.local/lost-marbles/public 中的采集文件。获取脚本按记录的 SHA-256 核验运行时，已核验过的文件可离线复用。第三方模块的再分发授权尚未核实。
