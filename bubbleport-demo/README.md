# 泡泡星港 · 宽版赛道试玩

独立的浏览器 demo，场景参考此前 chat「构思科幻微缩赛道模型」中的 Bubbleport 微缩乐园。薄荷、象牙白、蜜桃色的树脂设施，配暖窗灯、苏打店、摩天轮、土星装置和小机器人。场景、赛道路面和碰撞为本 demo 自编的程序化实现，未导入 Lost Marbles 的生成器、赛道网格或贴图。

## 试玩

```sh
python3 -m http.server 8891 --directory bubbleport-demo/dist
```

打开 `http://localhost:8891`，选择路段和宽度，点击「出发试玩」。WASD / 方向键移动，空格跳跃，R 重来，V 切换全景，Escape 暂停。手机提供同时按住的前进、左右与跳跃按钮。

- 星尘绕行：六个错位胶囊障碍，绕行或跳过。
- 月面摆锤：两个独立转轴的摆锤，真实移动接触与冲量。
- 轨道回环：左侧加速入环，右侧平缓旁路，再汇合抵达终点。

原宽 16 与加宽 19.2 可即时切换。切换后从起点重来，以同一角色半径、控制参数、机关数量和时间规律比较。路段是三个独立测试站，未拼成完整五关比赛，也未实现多人。

## 精确几何和碰撞

`dist/course.mjs` 同时输出显示路面和球体碰撞三角形，精确通行宽度为 16 或 19.2；回环分支宽度同步增加 20%。运行时由同一三角形确定地面接触与护栏边界。六个障碍的位置、数量、尺寸固定，Hi3D 只替换可见外观。摆锤轴和胶囊/球形接触体由程序独立驱动。

`dist/physics.mjs` 是独立实现的固定步长球体控制器：120Hz 逻辑更新、每次两步接触更新（1/240s），支持惯性、重力、跳跃、护栏、静态胶囊和运动摆锤。回环使用其真实路面采样的磁性导向辅助，沿切线积分重力，保留横向转向、跳离和出口制动；没有把倒挂导向宣称为完全自由的刚体模拟。

显示用 GLB 不参与碰撞。导入后按照独立程序形体的目标包围盒规范外观尺寸，不以 AI 提示词中的数字视为已达标尺寸。

## 检查

```sh
node --test bubbleport-demo/tests/physics.test.mjs
```

15 项物理检查覆盖两个宽度下的稳定地面、跳跃、护栏、跌落复位，普通路段与摆锤通行，回环全倒挂与旁路完成，机关接触，确定性、精确加宽比例、靠边入环收口以及跳离导向。自动驾驶检查只验证这些已实现路段与指定输入，不保证所有输入均可通关。

浏览器检查包含实际按键到终点、路段切换、宽度切换、暂停/重开和手机布局。试玩使用本机已安装的 Chrome；完成截图与验证记录保存在 `review/`。

## 独立机关外观

两个 Hi3D 独立零件用于碰撞胶囊和摆锤头，原始模型保留在仓库忽略的 `.local/bubbleport-props/`。`prepare-props.py` 使用本机 Blender 减面、补法线、将贴图缩至 1K，再导出运行资产。模型来源、生成费用与处理数据见 `prop-sources.json`、`prop-preparation.json`。

本轮两张参考图 12 积分、两个 v3.0 高质/PBR GLB 共 90 积分，总计新增 102 积分；上一轮整段可行性验证 153 积分，本阶段累计 255 积分。
