# 续航 · 夜场换电机

[返回玩偶库](../README.md)

闭园铃响，它才开始给沿街的小灯换电芯。胸窗里两节琥珀色电芯，一节值班，一节备用。

![续航全身概念图](concept-v1.png)

## 步态与动作

抱着电芯匣时用短步保持平稳，站定后用双手抽换电芯。

## 双芯灯态

![续航三阶段状态板](references/motion-v1.png)

| 左格 | 中格 | 右格 |
|---|---|---|
| 左芯值班／画面左芯亮，右芯熄灭 | 交接供电／两芯短时同亮 | 右芯值班／左芯熄灭，右芯保持亮起 |
