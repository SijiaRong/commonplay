# 歪团 WOB

[返回角色总索引](../README.md)

## 角色定位

努力装镇定的软胶团子。已收录在[游戏角色清单](../../../teddy-playground/dist/slide/characters.json)。

## 外形与材质

浅紫豆形身体、偏侧低折角、短歪嘴和奶油色小脚。

![歪团 WOB视觉参考](concept-v1.png)

## 动作与赛道反馈

起跳预备、腾空和落地都有压扁拉伸，短臂小幅摆动。游戏网格已去除生成模型多出的尾巴并修补背面。
