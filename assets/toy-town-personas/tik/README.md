## 角色定位

发条维修员。已收录在[游戏角色清单](../../../teddy-playground/dist/slide/characters.json)。

## 外形与材质

砖红积木头、蜂蜜色木桶身、薄荷色按钮和黄铜发条。

![滴克 TIK视觉参考](concept-v1.png)

## 动作与赛道反馈

独立发条骨骼在助跑与庆祝时转动；游戏版缩短了原模型的发条轴。
