# 土星回旋滑梯 MVP

从仓库根目录运行 `python3 -m http.server 8786 --bind 127.0.0.1`，打开 <http://127.0.0.1:8786/saturn-slide-mvp/>。页面使用仓库中的 Three.js、GLTFLoader、工作室环境图和土星地标。

**试玩关卡**使用 Hi3D 原件上层的一段 180° 带纹理网格。对原件半径 0.28 的一圈垂直采样显示，上下层始终分离，表面高度分别约为 0.059～0.116 和 −0.120～−0.052。因此试玩将原件减面、截取半圈，沿行进方向重新设置落差，并保留原 UV、底色和金属粗糙度贴图，得到 `slide-half.glb`。三个半圈首尾接续，每半圈下降 4 个单位。入口和出口分别接 8 和 14 单位直道。中央保留已有土星柱柱身，柱顶使用蜜桃气泡亚克力球和黄铜发光环。

**Hi3D 原件**按需读取资源库中的原始 GLB，方便对照。缝线小熊使用泡泡星城的毛绒材质和角色动画，采用沿轨道前进的简化动力学，可横移、刹车。弯道的接触高度通过查询渲染三角形取得，横移限制在净空范围。启动时沿中心线及两侧检查有效接触高度。此 demo 独立于正式第二关。
